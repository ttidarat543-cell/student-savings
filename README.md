# ระบบออมเงินนักเรียน

หน้าเว็บระบบออมเงินนักเรียน เชื่อมกับ Google Sheets ผ่าน Google Apps Script

## ใช้งาน
- **หน้าแรก** กด "สำหรับครู" แล้วเข้าสู่ระบบด้วยรหัสผ่านผู้ดูแลเดิมของระบบ
- **หน้าครู** ภาพรวม · บันทึกฝาก–ถอน · รายชื่อนักเรียน · สรุปยอดรายคน · พิมพ์รายงาน A4 · ตั้งค่า · เปลี่ยนรหัสผ่าน
- **QR ฝากเงิน** ในหน้าครู กด "QR ฝากเงิน" รายคน หรือ "พิมพ์บัตร QR ทั้งชั้น"
  ครูสแกนด้วยกล้องมือถือ แล้วใส่จำนวนเงินเพื่อฝากเข้าบัญชีของนักเรียนคนนั้นได้ทันที ไม่ต้องเข้าสู่ระบบ

## ความปลอดภัยของ QR
- ลิงก์ใน QR มีกุญแจสุ่ม 24 ตัวอักษรต่อคน เดาลิงก์ของคนอื่นไม่ได้
- ทำได้เฉพาะ "ฝาก" ไม่เกิน 500 บาทต่อครั้ง ถอนไม่ได้
- บันทึกผู้บันทึกเป็น "สแกน QR" ตรวจย้อนหลังได้ในชีต
- บัตรหาย: กด "สร้าง QR ใหม่" บัตรเก่าจะใช้ไม่ได้ทันที

## ติดตั้งฝั่ง Google Apps Script
1. เปิดโปรเจกต์ Apps Script เดิมของระบบ (ที่มี Code.gs)
2. เพิ่มไฟล์ใหม่ชื่อ `WebApi` แล้ววางโค้ดจาก `WebApi.gs` (ห้ามแก้ Code.gs)
3. Deploy > Manage deployments > แก้ไข > Version: New version > Deploy
4. URL /exec เดิมใช้ต่อได้ ตั้งไว้ใน `CONFIG.API_URL` ใน `index.html` แล้ว
